# WorshipWave 🎵

A Christian music discovery app built with Streamlit.

## Languages
English, Hindi, Kannada, Spanish, and Konkani.

## Features
- Search and filter by language/category
- Favorites and a temporary playlist
- YouTube search links and embedded playback for configured video IDs

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy
Push these files to GitHub, then connect the repository to Streamlit Community Cloud.

Note: The included entries are starter placeholders. Add verified official YouTube video IDs to `youtube_id` to embed a specific recording. Favorites and playlists are session-based and are not permanent user accounts.
